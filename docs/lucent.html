Lucent

One accent colour, softened, written into the programs you use. Switch it off and they all go back to a quiet monochrome.

How it works

YASB writes your Windows accent colour to a file (yasb_colors.css). Lucent reads it, softens it (a slider keeps only as much of the colour as you like), builds a few shades, and writes theme files for each program. It runs when you press Apply now, or right after you apply a new wallpaper. Never in the background.

You can also pick the accent yourself instead of following Windows: a colour picker with presets, a field to drag in, and a softness knob.

Use it

  1. Open Bento Settings, then the Lucent page.
  2. Switch the theme on. Set Softness and the Accent (Windows' own, a preset, or your own).
  3. Open a program's card to give it its own accent, or its own grey, or to switch it off.
  4. Press Apply now. Programs that read their theme at start (Zen, Helium, File Pilot, OBS, Spotify) get a Restart apps button.
Lucent off does not mean "unthemed": every program goes to a monochrome palette instead, with its own brightness, tint and grey that you can set in the Monochrome theme card.

Setting each one up

Zed

A theme, YASB Accent, in Zed's themes folder.

One-time step. Open Zed, Settings, Theme, and pick YASB Accent once. It follows the accent after that.

Get Zed: zed.dev

Discord

A theme file for BetterDiscord, Vencord or Equicord. Plain Discord cannot be themed.

One-time step. Install one of the three client mods, run Lucent once, then switch on yasb-colors in the mod's Themes page.

Get Discord: vencord.dev

Zen Browser

yasb-chrome.css and yasb-content.css in every profile.

One-time step. Restart Zen to see a change. If the colours do not appear, check that Zen is allowed to load custom stylesheets (the toolkit.legacyUserProfileCustomizations.stylesheets setting in about:config).

Get Zen Browser: zen-browser.app

Helium

A theme folder in ~\.config\yasb\themes\helium.

One-time step. On Helium's extensions page, turn on developer mode and load that folder as an unpacked extension, once. Restart Helium to see a change.

Get Helium: github.com/imputnet/helium

Obsidian

A CSS snippet, yasb-colors, in every vault.

One-time step. Switch it on in Settings, Appearance, CSS snippets. It overrides community themes.

Get Obsidian: obsidian.md

Windows Terminal

A colour scheme, YASB Accent.

One-time step. Pick it under a profile's Appearance, once.

Get Windows Terminal: github.com/microsoft/terminal

File Pilot

A colour scheme, YASB Accent.

One-time step. File Pilot must be closed while it is written. If it is open, Lucent offers to restart it.

Get File Pilot: filepilot.tech

Tacky Borders

The focused window's border colour.

One-time step. Installed by Bento. Pick the border colours on the Tacky Borders page.

Get Tacky Borders: github.com/lukeyou05/tacky-borders

Rainmeter

The Bento widget's highlights.

One-time step. Load YasbBento.ini from Rainmeter's Manage window, once.

Get Rainmeter: rainmeter.net

Spotify

A YASB colour scheme inside the Comfy Spicetify theme.

One-time step. Needs the Spotify desktop app (from spotify.com, not the Store) and Spicetify. The installer adds both Spicetify and Comfy. Spotify restarts to show a change.

Get Spotify: spicetify.app

OBS Studio

A variant of OBS's Yami theme, YASB Accent.

One-time step. Pick it once in OBS under Settings, Appearance, Theme. Restart OBS to see a change.

Get OBS Studio: obsproject.com

Not on the list?

Lucent works from small definitions: a file of colour variables and where to write it. Adding a program is a few lines, and pull requests are welcome on GitHub.
