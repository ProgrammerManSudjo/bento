Shortcuts

The defaults. All of them live in ~\.config\whkdrc and the scroll script, so change anything you like.

Windows and focus

KeysDoes
Alt + arrows (or J K L ;)Focus the window in that direction
Alt + Shift + arrowsMove the window
Alt + Q / Win + WClose the window
Alt + FMaximize
Alt + TFloat or tile the window
Alt + SpaceMonocle: one window fills the screen
Alt + Shift + ReturnPromote the window to the main spot
Ctrl + Shift + arrowsStack windows

Workspaces

KeysDoes
Alt + 1 to 8Go to workspace
Alt + Shift + 1 to 8Send the window to that workspace
Alt + scroll wheelPrevious or next workspace
Win + Alt + scrollSend the window to the previous or next workspace

Scroll hotkeys

KeysDoes
Win + scrollCycle focus through the windows
Win + Shift + scrollCycle focus between monitors
Win + Ctrl + scrollMove the window along the workspace order
Win + ZNext monitor

They live in an AutoHotkey script with a tray icon: click the icon to switch them off (for example before an anti-cheat game). Game mode does that for you.

Bar, layout, other

KeysDoes
Alt + Shift + OShow or hide the YASB bar
Alt + Shift + PPause or resume tiling
Alt + Shift + RReload komorebi's configuration
Alt + , / Alt + .Flip the layout horizontally or vertically
Ctrl + Shift + , / .Previous or next layout
Win + ReturnOpen Windows Terminal
