Windhawk

Windhawk customises the taskbar and windows. Bento does not install it for you (it needs administrator permission), but it makes the setup short.

Install it

Download it from windhawk.net and run the installer. Then press y in the Bento installer.

Recommended mods

The installer can add these in one administrator prompt (or add them yourself from the Windhawk app):

ModWhy
Click on empty taskbar spaceDouble-click, middle-click and so on to toggle the taskbar's auto-hide or run a command.
Taskbar auto-hide instant showA faster, smoother auto-hide.
Windows 11 Taskbar StylerLucent colours the taskbar buttons through this.
Notification Center StylerThe same for the notification centre.
Start Menu StylerThe same for the Start menu.
Custom Window Corner RadiusSofter window corners to match the bar.
Invisible Window BordersRemoves the gaps around windows when tiling.

Lucent and the taskbar

Turn on Windhawk under Advanced on the Lucent page. Applying it asks for administrator permission each time, because Windhawk keeps its settings where only administrators can write.
