Configuration

Everything Bento sets up is a plain file in your user folder. The settings app edits them for you, and you can edit them yourself at any time.

Bar~\.config\yasb
Tiling~\.config\komorebi
Hotkeys~\.config\whkdrc
Borders~\.config\tacky-borders

Where the files are

FileWhat it controls
yasb\config.yamlThe bar: its position and size, which widgets sit left, centre and right, and each widget's options. Made by the installer from a template with your own folder filled in.
yasb\styles.cssThe bar's look: capsules, colours, spacing, fonts.
yasb\yasb_colors.cssYour Windows accent colour, written by YASB. Lucent reads it. Do not edit by hand.
yasb\themes\The monochrome palette and Lucent's generated theme files.
komorebi\komorebi.jsonMonitors, workspaces, gaps, borders, animation and layout.
komorebi\applications.jsonPer-application rules: which windows float, which are ignored, which get a special border.
komorebi\komorebi-scroll.ahkThe scroll hotkeys, the tray icon and the game mode watcher.
komorebi\game-mode.ps1The one-line switch other tools call to turn game mode on or off.
whkdrcEvery keyboard shortcut. See Shortcuts.
tacky-borders\config.yamlBorder colours, thickness, animation and effects.
%LOCALAPPDATA%\yasb-settings\settings.txtThe settings app's own remembered choices: Lucent, per-program accents, monochrome tones.

Environment variables

The installer sets two user variables so komorebi and whkd find their files. They are the only environment change Bento makes.

VariablePoints to
KOMOREBI_CONFIG_HOMEThe folder with komorebi.json and applications.json.
WHKD_CONFIG_HOMEThe folder holding whkdrc.

Reloading after a change

You changedDo this
YASB config or stylesNothing: YASB reloads when the file is saved. If it ever does not, run yasbc reload.
komorebi.jsonkomorebic reload-configuration, or Alt + Shift + R.
applications.jsonkomorebic reload-configuration does not re-read this file. Use komorebic replace-configuration with the path to komorebi.json instead.
whkdrcRestart whkd, or stop and start komorebi with whkd.
Tacky Borders configRestart Tacky Borders. The settings app offers to do it.

Useful commands

yasbc toggle-bar        # show or hide the bar
yasbc reload            # re-read the YASB config
komorebic stop          # stop the tiling manager (windows are handed back)
komorebic start --whkd  # start it again, with the hotkey daemon

Monitors

The bar template uses screens: ["*"], which puts a bar on every monitor. To use one monitor only, replace the star with its name (YASB lists the names in its log). komorebi's workspaces are defined per monitor in komorebi.json, in the order komorebi reports them.

Start with Windows

A scheduled task named Bento Startup runs stagger-startup.ps1 at sign-in. It starts komorebi, whkd, the scroll script, YASB, Tacky Borders and Rainmeter in a fixed order with short pauses, so none of them races the others. Anything that fails to start is written to %TEMP%\stagger-startup.log.

Backups

When the installer would replace a file that already exists, the old one is kept next to it as name.backup-<time>. Delete them whenever you are happy.
